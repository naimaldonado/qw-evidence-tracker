Conecta el Excel para ver la evidencia

El dashboard lee el archivo qw-evidence-tracker.xlsx y se actualiza solo cada vez que guardas cambios en él.

  1. Opción recomendada: abre la carpeta en VS Code y haz clic derecho sobre este HTML, «Open with Live Server». Se conecta solo, en cualquier navegador.
  2. Sin Live Server: en Chrome o Edge pulsa «Conectar Excel» y elige el archivo. El navegador lo vigila y actualiza el reporte al guardar.
  3. También puedes arrastrar el Excel a esta ventana.
